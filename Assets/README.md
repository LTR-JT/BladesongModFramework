# Shared menu asset pack

Assets/Cooked contains the original PCLAnchor pack used by the framework's native
menu root and by PCL anchors. Editable source lives in
[the PCL asset project](https://github.com/LTR-JT/PreconstructionLibrary/tree/main/Assets/Project).
Only original PCL assets are included; stock engine/game assets are references.
The historical asset path is retained to avoid breaking existing integrations.
