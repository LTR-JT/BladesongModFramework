# Bladesong modding platform

The framework provides compatibility and shared game UI. The optional BladesongModManager maintains installations. The independent Developer SDK targets the runtime API, not an installer.

Start with [architecture and audit](manager-independence.md), [installation](installation.md), [package standard](https://github.com/LTR-JT/BladesongSDK/blob/main/Documentation/package-standard.md), or [your first mod](https://github.com/LTR-JT/BladesongSDK/blob/main/Documentation/first-mod.md). API 1.0.0 and frozen historical mods remain supported. This split is an unpublished candidate awaiting live testing and release authorization.
