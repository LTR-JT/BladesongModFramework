# Distribution

See [portable packages](https://github.com/LTR-JT/BladesongSDK/blob/main/Documentation/package-standard.md), [component architecture and ownership](manager-independence.md), [installation](installation.md), and [independent releases](releasing.md).

The compatibility runtime never downloads or installs mods. The optional manager uses author-hosted manifests and a name/repository-only discovery index. Any compatible external manager can implement the same package mapping and dependency standard. Vortex integration is future work and is not verified.
