# Contributing

Open a focused issue or pull request with reproduction steps, the game branch,
mod/framework versions, and relevant log excerpts. Remove personal paths and
account details before sharing logs. Never upload saves or other users' builds
without permission.

Run the checks in the README before submitting. Add a meaningful regression
fixture when changing compatibility, serialization, input, or installation.
Keep existing saves, library data, stable APIs and established behavior working.
Do not weaken executable guards to accept an unknown build.

Original contributions are accepted under the repository's MIT license.
Third-party work must keep its license, attribution and provenance.
