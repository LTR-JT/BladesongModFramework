Initial public community preview.

- Runtime archive for manual installation, plus an in-game update archive and hashed release metadata.
- Main and Bleeding Edge compatibility through framework-owned exact-build adapters.
- Existing library/save locations retained; native guards remain enabled.

Install the Runtime ZIP into the outer Bladesong folder. The BMF ZIP is for the
in-game installer after framework setup. UE4SS is installed separately.
Native adapter changes still require live validation on each corresponding game build.
